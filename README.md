# Office Artifacts: The One-Line Placard Contest

A make.fun bounty entry: one museum placard (at most 180 characters) for an
ordinary office object, written as if it were an ancient artifact — with a
catalogue date, a material and a donor.

> Shrine of the Shared Lunch, c. 2020. Steel, glass, other people's fish.
> Heated offerings in ninety seconds; forgave no one. Loan of the Break Room.

The program is stdlib-only Python: it writes the placard to `/output/entry.txt`.
